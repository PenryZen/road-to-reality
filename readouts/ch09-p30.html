明明叫「正」，为什么条件写成 p < 0

§9.5 从傅里叶变换看频率分裂 · 第 30 页的定义到底在说什么

这一条定义，读到的人几乎都要卡住一下：

定义在整条实直线上的（复）函数 f(χ)，若其傅里叶变换 g(p) 对一切 p > 0 都为零， 就说它是正频率的。这时 f(χ) 只由形如 eipχ（p < 0）的成分组成。

名字叫「正」，条件却是 p 小于零。这不是笔误，也不是您看反了。 这一页其实给了两条等价的说法，再加上一个看起来像作弊的插曲。 我们就按这三步走一遍，最后落在它真正的几何上。

一、先把两句话合成一句

定义里有两句：一句管变换域（g(p) 在 p > 0 上全为零）， 一句管原函数域（f 只含 p < 0 的成分）。 它们不是两条要求，是同一件事的两种说法——就像说 「这袋里没有红球」和「这袋里全是蓝球」，前提是一共只有两种球。

取一个具体的正频率函数，拿它试一遍：

f(χ) = e−iωχ · e−χ²/2σ²　　（ω > 0，高斯包络的一支纯音）
试一试
拖动 ω，看频谱的峰往哪边跑
约定：
右边那块浅红区域是 p > 0。定义要求 |g| 在那儿恒为零——您看峰是不是始终躲着它。

我验过：ω 取 1、3、5，峰始终落在 p = −ω， 而 p > 0 那一侧的 |g| 分别只有 10−8、10−22、10−43——小到等于没有。 所以两句话确实是一句话。

二、那个「作弊」的插曲：欧拉会怎么想

原文特意加了一句括号，说欧拉很可能为此担心。担心的是什么？ 是这样拼出来的 g(p) 太不像话：p < 0 上有值，p > 0 上硬是零。

这样的 g(p) 看着就是把 p < 0 上的非零函数与 p > 0 上的零硬拼在一起， 拼得明目张胆。可它似乎表示的却是 f(χ) 一个完全体面的「全纯」性质。

欧拉那代人的「函数」要求是一个式子给到底。 半边有值、半边恒零，从光滑性看是极不自然的拼接——g(p) 在 p = 0 处连连续都谈不上。

妙就妙在反过来：这个作弊的频谱，对应的偏偏是 f(χ) 一个体面得不能再体面的性质。 粗糙的频谱 ↔ 光滑的解析性。这正是这一节要请您看的事。

三、「正」说的不是 p，是能量

这才是真正别扭的地方。答案一句话：「正」说的是能量，不是 p。

量子力学里，能量为 E 的定态随时间这样演化：

ψ(t) = ψ(0) · e−iEt/ħ

而傅里叶变换的通用写法是 eipχ。 把 ψ 塞进这个标准形，就得令

p = − E / ħ

于是能量越正，p 越负：

试一试
拖能量 E，看 p 怎么翻号
把 E 拖成负数试试——p 立刻变正，而「正频率」这个称呼也跟着跑到另一边去了。

彭罗斯要的是「正频率 = 正能量 = 物理上真实存在的粒子」。 为了让这三者对齐，他只能把正频率定义成 p < 0。

这是约定，不是推导。换一本用 e+iEt 的书，符号整套翻过来—— 但「劈成两半」这件事一点不变。

四、这一页真正的几何：实圆把球劈成两半

前面都还是铺垫。这一页真正的新东西，是给出正频率的几何说法—— 跟前面讲傅里叶级数时用的是同一套招数：不看频谱，看能不能往外延拓。

做法是这样的：把 χ 看成实轴上各点的标记（在实轴上取 χ = x）。 然后把这条实轴连同点 χ = ∞ 一起搬到黎曼球上。 实轴加上无穷远点，在球面上闭合成一个大圆——书里管它叫实圆。

实圆 = 实轴 + 点 χ = ∞，在黎曼球上闭成一个大圆

关键在于：一个大圆必然把球面劈成两个半球。 其中「外面」那一个，就是复平面标准图像里的下半平面。

试一试
拖 η，看这个点住进哪半边
左栏是 χ 复平面，右栏是黎曼球。两栏是同一个点的两种看法：往下走 = 落进「外侧」那个半球。

于是这一页给了两条等价的说法：

g(p) 在 p > 0 全为零　⟺　f 能全纯延拓进「外侧」半球（= 下半平面）

左边是频谱条件，右边是几何条件。一个管变换域，一个管延拓—— 它们居然是同一件事，这才是这一节最值得停下来看的地方。

五、跟第 9.3 节的「劈两半」接上

还记得 9.3 节吗？那里把黎曼球劈成南北两半，正频住一半、负频住一半。 现在是同一件事的实直线版：球面那两半，在实轴这个极限下摊成了复平面的上下两半。

试一试
拖 η，看整条链怎么一起翻面
四个格子会同时变色。拖过 η = 0 的那一刻，整条链一次性翻面。

把「哪半叫正」忘掉，记住这条就够：

数学上真正重要的，不是哪半叫正，而是「劈得成两半，而且劈法唯一」。

六、这一页为什么值得单独讲

收获说明
一条定义，两种读法频谱条件（g(p) 在 p> 0 全零）和几何条件（能全纯延拓进外侧半球）是同一句话
把「作弊」变成工具g(p) 拼得再难看，f(χ) 那边照样是解析的；反过来，正频率函数被它在下半平面的值唯一确定
「正」= 正能量p < 0 只是 −i 带来的符号；换个约定整套翻号，劈两半这件事不变
接上 9.3 节球面南北两半，在实轴极限下摊成复平面的上下两半；彭罗斯要的时间之矢，就埋在这个剖分里
一句口诀
定义给了两句，但它们是同一件事：频谱在 p > 0 上全零 ⟺ 能延拓进「外侧」半球。
「正」的正 = 正能量；p < 0 只是那个 −i 带来的。
别扭的地方是约定，结实的地方是剖分——劈得成两半、且劈法唯一，才是这一节的骨头。
