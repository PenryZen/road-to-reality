# 通向实在之路 · 精读学习站

《The Road to Reality》（Roger Penrose）的 34 章逐章精读 + 闪卡调度 + 自测关卡，纯静态网页。

- **地图**：六个区域、61 个关卡，延迟提取才算通关
- **精读**：每章按「核心 → 讲授 → 定义 → 比喻 → 例子 → 推导 → 误区 → 小结」推进，公式走 KaTeX
- **朗读**：浏览器语音 / 在线语音 /（本机代理时）微软神经语音
- **AI 学伴**：自带 API Key，三种模式（只追问 / 批改 / 自由问答）

## 按需加载

首屏只拉地图需要的 12 个文件（约 430KB）；章节正文、原书插图、交互图、KaTeX 与楷体字库
都在打开对应关卡时才取，由 `lazy.js` + `gen/lazy/manifest.js` 驱动。

```
首屏            12 个请求 / ~430 KB
打开一章         + 本章正文（~85 KB）+ 插图 + 该章用到的 viz + KaTeX + 字库
```

清单由 `gen/build-lazy.py` 生成；`node build.js` 会把所有碎片内联成单文件版。

## 部署

纯静态，没有后端。GitHub Pages / Cloudflare Pages / 任意对象存储都能放，
注意站点会部署在子路径下（`/仓库名/`），所有引用都是相对路径，无需改配置。

`.nojekyll` 必须保留：否则下划线开头的文件会被 Jekyll 忽略。

## 隐私

学习进度与模型配置只存在浏览器 localStorage。
API Key 只在你发起对话时直接发往你自己填的 Base URL，本站没有后端，收不到任何东西。
