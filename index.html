连不上？三种典型情况与解法

① 跨域被拦（最常见的报错）。浏览器会打印 CORS policy 或本页提示「无法连接到…」。云端 API（含 DeepSeek 官方）与部分本地服务都不允许网页直接调用。解法：下载本仓库的 ds-proxy.py，在本机执行

python3 ds-proxy.py --upstream https://api.deepseek.com --key sk-你的key

然后把这里的 Base URL 改成 http://127.0.0.1:8787/v1，Key 留空（key 已放在代理端，不进浏览器），模型名照旧。

② 混合内容拦截。若页面以 https:// 打开，而接口是 http://127.0.0.1，浏览器会直接拒绝。用本地单文件打开（file://）或让两者协议一致。

③ 密钥或模型名不对。报 401 是 key 问题，报 404 / 400 多为 Base URL 少了 /v1，或模型名不存在——点「拉取列表」看看服务端到底有哪些模型。

DeepSeek 官方模型名：deepseek-v4-pro（思考模式）、deepseek-v4-flash（非思考）。旧的 deepseek-chat / deepseek-reasoner 已于 2026-07-24 弃用。

三条不可让渡的红线

  • 先生成，后辅助：任何任务先独立做，AI 只做批改与追问。
  • 答案不算产出：合上 AI 的回复，凭记忆重写一次，才算完成。
  • 事实必核查：AI 给的数字与引用一律回到本站讲稿二次核对——它会一本正经地编页码。
